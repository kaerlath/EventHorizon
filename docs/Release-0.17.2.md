# Event Horizon 0.17.2

Calendar capsules are slimmer, with labels 20% smaller at the same Appearance setting, less vertical padding, smaller information icons, thinner outlines and softer glows. At the default font size, each capsule is about 40% shorter. Spacing between capsules drops from six to four pixels.

Month view displays up to six event lanes instead of four; week view displays up to ten instead of seven. Additional events remain available through the day list. Category colors, multi-day continuity, information tooltips, and lower event details continue to work as before. Appearance's calendar text size still adjusts the capsules.

Plugin-only update: relay 0.17.1 remains current. Debug and Release builds pass; in-game visual and pointer interaction testing is still needed. Offline dependency vulnerability lookup was unavailable.
