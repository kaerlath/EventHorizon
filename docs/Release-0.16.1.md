# Event Horizon 0.16.1

Calendar event titles wrap at the available day width, including long words. Week rows grow to accommodate displayed titles, and the time-zone caption wraps in narrow windows.

Appearance > Calendar fonts sets personal default event text size (70-150%) and color. View an event > Personal calendar text overrides its size/color on this computer, including community events; turn off the override to inherit defaults. Discord announcements are unchanged.
