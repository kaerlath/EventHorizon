# Event Horizon 0.17.0

Create continuous multi-day events or one event with up to 12 separate sessions. The calendar shows each active day, keeps session gaps empty, and draws colored range bars. Personal in-game reminders and opted-in private Discord DMs follow each session.

Official FFXIV events now appear as optional information-only calendar entries, with local times and links to Square Enix. The initial verified catalogue includes Yo-kai Watch, Moogle Treasure Trove, and A Nocturne for Heroes. Future unannounced dates are not estimated; catalogue changes ship with plugin updates. These entries never publish or sync to Discord/Google.

Discord and Google retain one overall event range with a complete session itinerary. Multiple-session Google entries are marked Free. Google’s own reminders apply to the overall start. The native Discord description may be shortened to make room for the itinerary; the announcement keeps the complete description.

Deploy relay 0.17.0 before using the new schedule options online. Help & Walkthrough and the player guide explain the new choices.

Validation: Release and Debug builds, 110 .NET checks, and 102 Cloudflare checks. In-game interaction and live Discord/Google verification still need testing. Dependency vulnerability lookup was unavailable during the offline build.
