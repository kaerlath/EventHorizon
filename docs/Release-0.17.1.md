# Event Horizon 0.17.1

The calendar uses compact color-coded capsules for all event types: Seasonal Original (SE-OE), Seasonal Recurring (SE-RE), Seasonal Special (SE-SE), Game (GE), Community (CE), Social (SO), DM’d (DM), Free Company (FC), and Personal (PE).

Hover the information icon for only type, title and local date/time. Select the capsule body for full event details beneath the calendar. Multi-day capsules use stable lanes and connect across consecutive dates; separate sessions retain their gaps. Overflow days retain all entries in the lower event list.

The event editor now has an event type selector and comma-separated tags. Categories do not grant access or change visibility. Personal events display PE; official Square Enix entries remain read-only and calendar-only. Updated Help & Walkthrough explains the corrected labels and interactions.

Deploy relay 0.17.1 to preserve categories and tags for published, recovered and community events. This replaces the unpublished preliminary 0.17.1 badge design.

Validation: 118 .NET checks, 103 relay checks, Debug and Release builds. In-game visual and interaction testing remains necessary. Dependency vulnerability lookup was unavailable during the offline build.
